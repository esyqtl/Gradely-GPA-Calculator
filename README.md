# Gradely 🎓

Gradely is a simple Android app that helps students calculate their GPA.

## Features

* Add subjects
* Enter credit hours
* Select grades
* Calculate GPA
* Reset the calculation

## Built With

* Java
* Android Studio
* XML

## GPA Calculation

Gradely calculates GPA using:

**GPA = Total Grade Points ÷ Total Credit Hours**

For each subject:

**Grade Point × Credit Hours**

| Grade | Grade Point |
| ----- | ----------- |
| A     | 4.00        |
| A-    | 3.67        |
| B+    | 3.33        |
| B     | 3.00        |
| B-    | 2.67        |
| C+    | 2.33        |
| C     | 2.00        |
| D     | 1.00        |
| F     | 0.00        |

## How to Run

1. Download or clone this repository.
2. Open it in Android Studio.
3. Run the app on an emulator or Android phone.
